# Changelog

Version bumps move these notes into a numbered section. Review the notes before tagging.

## [Unreleased]

- Disable Hint once a Klondike, FreeCell or Spider deal is won, instead of suggesting Undo or restart.
- Celebrate solitaire wins with bouncing finished cards that leave a trail; any tap, click or key clears them, and reduced-motion settings skip it.

## [0.4.0]

- Add Minesweeper with three presets, mouse/keyboard/touch controls, safe openings, exact-field replay and independent offline saves.

## [0.3.0]

- Add explicit release-merge tagging and dispatch of the Windows draft-release build.

- Show the shared app version and build commit in About on web and Windows.
- Add one command to bump the shared version, synchronized metadata and offline cache.

## [0.1.0]

- Four offline card games: Klondike, FreeCell, Spider and Hearts.
- Windows x64 executable built from the shared frontend, with saved games and Undo.
